# 🏮 등불지기: 늪의 밤

늪에 밤이 내렸습니다. 등불 하나로 새벽이 올 때까지, **10분을 버티면 승리**하는 탑다운 서바이벌 게임입니다.
이동만 하면 공격은 저절로 나가고, 쓰러진 적이 남긴 구슬을 모아 레벨을 올리며 능력을 하나씩 고릅니다.

설치할 것 없이 브라우저에서 바로 돌아갑니다. 컴퓨터와 휴대폰 모두 됩니다.

## 하는 방법

| 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 이동 | WASD 또는 방향키 | 화면을 손가락으로 끌기 |
| 일시정지 | Esc 또는 P | 오른쪽 위 ❚❚ 버튼 |
| 레벨업 선택 | 1, 2, 3 키 또는 클릭 | 터치 |

**난이도**
- **쉬움**: 적 체력 70%, 적 공격력 50%, 적이 덜 나오고 내 체력은 150. 아이들에게 추천해요.
- **보통**: 기본 난이도. 체력 100.

최고 기록은 난이도별로 그 브라우저에 저장됩니다.

## 무기와 장비

**무기** (각각 최대 6레벨)
- 🔥 불씨 탄: 가장 가까운 적을 자동 조준
- 🏮 등불 결계: 내 주위에 계속 피해
- ✨ 반딧불 무리: 주위를 돌며 적을 밀어냄
- ⚡ 늪 번개: 화면 안의 무작위 적에게 낙뢰
- ❄️ 서리 파편: 바라보는 방향으로 부채꼴 발사

**장비** (각각 최대 5레벨)
🕯️ 피해량, 👢 이동 속도, 🧥 최대 체력, 🧭 구슬 끌어오는 범위, ⏳ 공격 대기시간, 🌿 체력 회복, 🎩 공격 범위

**적**: 나방, 이끼 망령, 늪 바위. 약 55초마다 나방 떼가 포위하고, 2분마다 보스 **늪의 군주**가 나타납니다. 보스를 쓰러뜨리면 보물 상자(무료 레벨업)와 회복 하트를 떨어뜨려요.

## 내 컴퓨터에서 바로 실행

`index.html` 파일을 더블클릭하면 브라우저에서 열립니다. 끝!

## GitHub Pages로 링크 만들어 공유하기

1. GitHub에서 **New repository**를 눌러 저장소를 만듭니다 (예: `lantern-keeper`). 공개(Public)로 만드세요.
2. 저장소 화면에서 **Add file → Upload files**를 눌러 이 폴더의 파일을 모두 끌어다 놓고 **Commit changes**를 누릅니다.
3. **Settings → Pages**로 가서 *Source*를 **Deploy from a branch**, 브랜치를 **main**, 폴더를 **/(root)** 로 두고 **Save**를 누릅니다.
4. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/lantern-keeper/` 주소가 나타납니다. 이 링크를 가족에게 보내면 누구나 바로 플레이할 수 있어요.

파일을 고쳐서 다시 올리면 몇 분 안에 링크에도 반영됩니다.

## 파일 구성

```
index.html   화면 구성 (시작, 레벨업, 일시정지, 결과 창)
style.css    디자인
game.js      게임 로직 전부
```

## 직접 고쳐 보기

아이들과 함께 숫자를 바꿔 보며 게임을 바꿔 보세요. 모두 `game.js` 안에 있습니다.

| 바꾸고 싶은 것 | 찾을 곳 |
|---|---|
| 승리까지 걸리는 시간 (초) | `const WIN_T = 600;` |
| 난이도 수치 | `const DIFF = { ... }` |
| 적의 체력, 속도, 공격력, 경험치 | `const ETYPES = { ... }` |
| 무기와 장비 이름, 설명 | `const WEAPONS`, `const PASSIVES` |
| 무기 성능 | `function updWeapons` |
| 주인공 기본 속도 | `baseSpeed: 155` |
| 보스 등장 간격 | `S.nextElite += 120;` |
| 회복 하트, 구슬 자석이 나오는 확률 | `HEART_DROP`, `LURE_DROP` |
| 레벨업 속도 (경험치 통 크기) | `XP_LATE_LV`, `XP_LATE_MUL` |
